\# **Employee Attrition Prediction Using Machine Learning**



\## **Project Overview**

This project focuses on predicting whether an employee is likely to leave an organization based on various employee-related attributes.



\## **Objectives**

\- Understand employee attrition through domain analysis.

\- Identify important factors influencing employee turnover.

\- Build machine learning classification models to predict employee attrition.



\## **Technologies Used**

\- Python

\- Pandas and NumPy

\- Matplotlib and Seaborn

\- Scikit-learn

\- Imbalanced-learn



\## **Machine Learning Algorithms**

\- Decision Tree Classifier

\- Random Forest Classifier



\## **Methodology**

1\. Domain Analysis

2\. Exploratory Data Analysis (EDA)

3\. Data Preprocessing

4\. Feature Selection

5\. Handling Class Imbalance using SMOTE

6\. Model Training and Hyperparameter Tuning

7\. Model Evaluation



\## **Results**

The tuned Random Forest model achieved 87.5% test accuracy.



\## **Files**

\- HR-Employee-Attrition.csv – Dataset

\- Random\_Forest\_Class.ipynb – Jupyter Notebook containing the implementation and analysis.
